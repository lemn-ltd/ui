## Public Showcase

[showcase.ui.le-mn.com](https://showcase.ui.le-mn.com) is public and read-only.
It renders real LEMN components and blocks, exposes current catalog/agent read
models, and demonstrates every immutable System branding in complete
light/dark modes without changing component functionality.

It owns:

- interactive component and block examples;
- responsive, accessibility, interaction, and visual evidence;
- public provider and capability read models with no credentials;
- `catalog.json`, `llms.txt`, and `llms-full.txt`;
- deterministic fixtures for review.

## Showcase Admin

[admin.showcase.ui.le-mn.com](https://admin.showcase.ui.le-mn.com) is a separate
Cloudflare Access-protected deployment. It is the safe place to experiment with
provider mappings, compare variations, inspect conformance, create branding
previews, exercise Studio's host contract, and create proposal bundles.

Admin does not write the active registry manifest directly and never receives a
personal GitHub token. A least-privilege AgentOps/GitHub-sync plan/apply flow
creates a reviewable branch or pull request. Registry changes still pass normal
review, conformance, license, changeset, and release gates.

## Brand Studio

Brand Studio is a reusable package, not a deployment or control plane. It edits
a controlled `BrandingDefinition`, compiles a real component preview, exposes
diagnostics, and emits typed host intents. Showcase and Showcase Admin keep
experiments in memory only. AgentOps supplies Workspace authorization,
persistence, optimistic hashes, idempotency, publication, activation, previews,
and audit.

## Local development

```bash
pnpm dev:showcase
pnpm dev:showcase-admin
```

The default local ports are `6500` for Showcase and `6502` for Showcase Admin.
