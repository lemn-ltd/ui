The showcase is deployed separately at
[showcase.ui.lemn.ai](https://showcase.ui.lemn.ai).

It owns:

- interactive component examples
- responsive visual states
- accessibility and behavior checks
- `catalog.json`, `llms.txt`, and `llms-full.txt`
- visual regression baselines

Local development:

```bash
pnpm dev:showcase
```

The local showcase runs at `http://localhost:6500`.
