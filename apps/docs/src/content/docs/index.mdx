`@lemn-ltd/ui` is the shared React design-system package for LEMN products.
This site is the human-facing documentation surface for installation, release
lifecycle, migrations, and operational ownership.

## Production surfaces

- Docs: [ui.le-mn.com](https://ui.le-mn.com)
- Showcase: [showcase.ui.le-mn.com](https://showcase.ui.le-mn.com)
- Component catalog JSON: [showcase.ui.le-mn.com/catalog.json](https://showcase.ui.le-mn.com/catalog.json)
- Agent guide: [showcase.ui.le-mn.com/llms.txt](https://showcase.ui.le-mn.com/llms.txt)
- Repository: [github.com/lemn-ltd/ui](https://github.com/lemn-ltd/ui)

## Ownership

Use this repository when a product needs a reusable component, token, layout, or
shared style migration. Product apps should consume the published package instead
of copying component CSS or deep-importing package internals.

## Documentation model

The docs site explains lifecycle, releases, and integration guidance. The
showcase remains the interactive source for component behavior, examples,
responsive states, and visual review.
