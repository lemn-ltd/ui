`@appranks/ui` follows SemVer for the published package.

- `PATCH`: bug fixes, internal implementation fixes, docs corrections, and non-breaking visual polish.
- `MINOR`: new components, new exports, new variants, additive props, and non-breaking behavior.
- `MAJOR`: removed exports, renamed props, changed semantics, or visual/behavior changes that require consumer migration.

## Release ownership

Feature authors or agents add a changeset to describe the release intent. The
release automation turns merged changesets into a release metadata commit that
updates `packages/ui/package.json` and `packages/ui/CHANGELOG.md`.

CI publishes the package when the generated version is not already present and
the registry owner/token can publish the package scope. If GitHub Packages
ownership is not aligned with the package scope, CI records a warning and still
deploys docs plus showcase.

## Commands

```bash
pnpm changeset
pnpm version:packages
pnpm release
```

Use prerelease versions only for explicit staged rollouts.
