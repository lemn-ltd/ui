El showcase se despliega por separado en
[showcase.ui.lemn.ai](https://showcase.ui.lemn.ai).

El showcase controla:

- ejemplos interactivos de componentes
- estados visuales responsive
- checks de accesibilidad y comportamiento
- `catalog.json`, `llms.txt` y `llms-full.txt`
- baselines de visual regression

Desarrollo local:

```bash
pnpm dev:showcase
```

El showcase local corre en `http://localhost:6500`.
