## Showcase publico

[showcase.ui.le-mn.com](https://showcase.ui.le-mn.com) es publico y read-only.
Renderiza componentes/blocks reales, expone catalogos para humanos/agentes y
demuestra cambios de Profile/mode sin cambiar funcionalidad.

## Showcase Admin

[admin.showcase.ui.le-mn.com](https://admin.showcase.ui.le-mn.com) es un deploy
separado protegido por Cloudflare Access. Permite experimentar con mappings de
proveedores, variaciones, conformance y previews de proyecto/Profile, ademas de
crear proposal bundles.

Admin nunca escribe directamente el manifest activo ni recibe un token personal
de GitHub. Un plan/apply AgentOps/GitHub-sync least-privilege crea un branch/PR
revisable que sigue los gates normales.

## Brand Studio

Brand Studio es un paquete reusable, no un deploy ni un control plane. Edita un
BrandProject controlado, compila preview/diagnosticos y emite intents tipados.
El host posee auth, persistencia, expected revision, idempotencia, publicacion,
rollback y audit.

```bash
pnpm dev:showcase
pnpm dev:showcase-admin
```
