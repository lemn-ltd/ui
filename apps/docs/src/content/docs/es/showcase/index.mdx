## Showcase publico

[showcase.ui.le-mn.com](https://showcase.ui.le-mn.com) es publico y read-only.
Renderiza componentes/blocks reales, expone catalogos y demuestra todos los
System brandings inmutables en modes completos light/dark.

## Showcase Admin

[admin.showcase.ui.le-mn.com](https://admin.showcase.ui.le-mn.com) es un deploy
separado protegido por Cloudflare Access. Permite experimentar con mappings,
variaciones, conformance, previews, contrato de host de Studio y proposal
bundles. No posee estado durable ni activacion de Workspaces.

Admin nunca escribe el manifest activo ni recibe un token personal de GitHub.
Los cambios de registry siguen review, conformance, licencias, changeset y
release normales.

## Brand Studio

Brand Studio es un package reusable, no un deploy ni control plane. Edita un
`BrandingDefinition` controlado, compila preview con componentes reales y emite
intents tipados. Showcase/Admin mantienen experimentos solo en memoria.
AgentOps posee auth, persistence, optimistic hashes, idempotency, publication,
activation, previews y audit.

```bash
pnpm dev:showcase
pnpm dev:showcase-admin
```
