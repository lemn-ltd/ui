Lemn UI es un ecosistema provider-first, no una coleccion de widgets reescritos
localmente. LEMN selecciona capacidades open source battle-tested de forma
individual, asigna exactamente un proveedor de registro a cada capacidad
semantica y expone una API estable y neutral con una capa minima de branding
compilado.

## Que posee este workspace

- `@lemn-ltd/brand-contract`: schema BrandProject versionado, validacion,
  compilador determinista, diagnosticos, CSS con scope, adaptadores de
  proveedores e integridad.
- `@lemn-ltd/ui`: componentes controlados, visualizaciones, estilos semanticos,
  blocks y catalogos publicos.
- `@lemn-ltd/brand-studio`: wizard controlado y sin persistencia para crear y
  previsualizar BrandProject JSON.
- Registry Git-authoritative con origen exacto, licencias, notices, adaptadores,
  conformance y estado de updates.
- Docs y Showcase publicos, mas Showcase Admin protegido por separado.

## Limites no negociables

- Los productos importan versiones exactas aprobadas de `@lemn-ltd/*`.
- Los productos no importan un proveedor UI para capacidades del catalogo.
- Los componentes consumen roles `--lemn-*` compilados, nunca BrandProject JSON
  crudo ni variables especificas por proyecto.
- El host resuelve y verifica branding antes del primer byte HTML.
- Fetching, routing, autenticacion, estado global, internacionalizacion,
  analytics, persistencia y politica quedan fuera de los paquetes UI.
