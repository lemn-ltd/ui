`@lemn-ltd/ui` es el paquete React compartido para el design system de
AppRanks. Este sitio es la documentacion humana para instalacion, lifecycle de
release, migraciones y ownership operativo.

## Superficies de produccion

- Docs: [ui.appranks.com](https://ui.appranks.com)
- Showcase: [showcase.ui.appranks.com](https://showcase.ui.appranks.com)
- Catalogo JSON: [showcase.ui.appranks.com/catalog.json](https://showcase.ui.appranks.com/catalog.json)
- Guia para agentes: [showcase.ui.appranks.com/llms.txt](https://showcase.ui.appranks.com/llms.txt)
- Repositorio: [github.com/appranks/ui](https://github.com/appranks/ui)

## Ownership

Usa este repositorio cuando un producto necesita un componente reutilizable,
token, layout o migracion de estilo compartido. Las apps consumidoras deben usar
el paquete publicado, no copiar CSS ni hacer imports internos.

## Modelo de documentacion

Este sitio explica lifecycle, releases e integracion. El showcase sigue siendo
la fuente interactiva para comportamiento, ejemplos, estados responsive y review
visual.
