Produccion tiene dos dominios publicos:

- `ui.le-mn.com` sirve este sitio Starlight de docs.
- `showcase.ui.le-mn.com` sirve el showcase interactivo como Worker SPA.

CI valida pull requests con typecheck, tests, build, metadata de release y
changeset status. Los pushes a `main` ejecutan el release workflow:

1. Valida sin mutar Cloudflare el owner de la Global API Key, la membresia, los permisos de escritura, el acceso a la zona y que no existan mapeos de dominio conflictivos.
2. Si hay changesets pendientes, crea y pushea un unico commit de metadata con el bump SemVer y changelog.
3. Captura la version y Git SHA de ese commit de release.
4. Publica cualquier version no publicada de `@lemn-ltd/ui` cuando el owner/token del registry puede publicar ese package scope.
5. Despliega docs y showcase con la identidad de build capturada.
6. Hace smoke de ambas superficies y rechaza metadata stale de version o Git SHA.

CI consulta la lista autenticada de versiones de GitHub Packages antes de
publicar. Solo una consulta exitosa que omita la version exacta permite la
publicacion. Los fallos de autenticacion, autorizacion, lookup del paquete, red
o alineacion scope/owner detienen el release en lugar de tratar la version como
inedita.

El job `Release And Deploy` es el unico que puede resolver credenciales de
produccion. Usa el GitHub Environment `production`, que exige aprobacion y
solo permite deployments desde la rama protegida `main`.

Secrets y variables requeridas en el Environment `production`:

- `PRODUCTION_CLOUDFLARE_API_KEY` con la Global API Key
- `PRODUCTION_CLOUDFLARE_EMAIL` para el owner de la Global API Key
- `PRODUCTION_STATUS_TOKEN`
- `GITHUB_TOKEN` de GitHub Actions

No crees credenciales productivas a nivel de repositorio. Los nombres
`PRODUCTION_*` hacen que un secret ausente en el Environment falle cerrado en
lugar de usar un repository secret con el nombre de la variable de runtime.

Los dos `wrangler.jsonc` son la fuente de verdad de cuenta y Worker. No uses ni
derives `CLOUDFLARE_API_TOKEN` desde la Global API Key: Wrangler requiere el par
`CLOUDFLARE_API_KEY` y `CLOUDFLARE_EMAIL` en este repositorio.
