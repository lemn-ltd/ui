Produccion tiene dos dominios publicos:

- `ui.appranks.com` sirve este sitio Starlight de docs.
- `showcase.ui.appranks.com` sirve el showcase interactivo como Worker SPA.

CI valida pull requests con typecheck, tests, build, metadata de release y
changeset status. Los pushes a `main` ejecutan el release workflow:

1. Si hay changesets pendientes, crea un commit de metadata de release con el bump SemVer y changelog.
2. Publica cualquier version no publicada de `@appranks/ui`.
3. Despliega docs a `ui.appranks.com`.
4. Despliega showcase a `showcase.ui.appranks.com`.
5. Hace smoke test de endpoints publicos.

Secrets y variables requeridas:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`
- `STATUS_TOKEN`
- `GITHUB_TOKEN` de GitHub Actions
