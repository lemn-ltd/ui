Configura GitHub Packages para el scope `@lemn-ltd`:

```ini
@lemn-ltd:registry=https://npm.pkg.github.com
```

```bash
pnpm add @lemn-ltd/ui@<published-version>
```

Importa componentes solo desde la superficie publica e importa el stylesheet una
vez en la raiz de la app:

```tsx
import { Button, Card, componentCatalog } from "@lemn-ltd/ui";
import "@lemn-ltd/ui/styles.css";
```

## Controles de tema

`ThemeToggle` cambia entre modo light y dark. `AccentColorPicker` permite mover
un puntero por una paleta y actualiza los tokens compartidos de accent en tiempo
real; tambien soporta flechas del teclado y un control de Hue.

```tsx
import { AccentColorPicker, ThemeToggle } from "@lemn-ltd/ui";

<AccentColorPicker />
<ThemeToggle />
```

Usa `applyToRoot={false}` o `persist={false}` cuando la aplicacion consumidora
controle el estado del tema. Los helpers `applyAccentColor`, `setAccentColor` y
`resetAccentColor` se exportan desde el mismo entrypoint publico.

## Reglas

- No hagas deep imports desde `@lemn-ltd/ui/src`, `@lemn-ltd/ui/dist` o internals.
- No importes Radix, `cmdk` o `sonner` directamente en productos para UI compartida.
- Agrega UI reutilizable aqui primero, publica una nueva version y actualiza consumidores.
- Usa [el showcase](https://showcase.ui.le-mn.com) para verificar comportamiento.
