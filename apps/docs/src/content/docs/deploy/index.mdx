The production deployment has two public domains:

- `ui.le-mn.com` serves this Starlight docs site.
- `showcase.ui.le-mn.com` serves the interactive showcase Worker SPA.

CI validates pull requests with typecheck, tests, build, release metadata, and
changeset status. Pushes to `main` run the release workflow:

1. If changesets are pending, create a release metadata commit with the SemVer bump and changelog.
2. Publish any unpublished `@lemn-ltd/ui` version when the registry owner/token can publish the package scope.
3. Deploy docs to `ui.le-mn.com`.
4. Deploy showcase to `showcase.ui.le-mn.com`.
5. Smoke public docs and showcase endpoints.

With GitHub Packages, `GITHUB_TOKEN` can publish package scopes owned by the
repository owner. If the package scope is owned elsewhere, CI records a publish
warning and continues the docs/showcase deployment; configure a dedicated
registry token or align the package scope before publishing.

Required secrets and variables:

- `CLOUDFLARE_API_KEY` (Cloudflare Global API Key)
- `CLOUDFLARE_EMAIL`
- `CLOUDFLARE_ACCOUNT_ID` (GitHub Actions variable for the Lemn DEV account)
- `STATUS_TOKEN`
- `GITHUB_TOKEN` from GitHub Actions
